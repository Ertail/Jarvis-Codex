# Review rubric

## Severity

- **P0 Critical**: immediate data loss, security compromise, or system-wide
  outage is likely.
- **P1 High**: core behavior is wrong, a major regression is likely, or required
  verification is absent.
- **P2 Medium**: real edge-case failure, maintainability risk, or incomplete
  requirement with bounded impact.
- **P3 Low**: worthwhile improvement that does not block the stated outcome.

## Completeness

Score each original requirement:

- **Complete**: implemented and supported by evidence.
- **Partial**: some behavior or evidence is missing.
- **Missing**: not implemented.
- **Not applicable**: explicitly out of scope with a reason.

Any Missing item blocks an unconditional completion claim. A Partial item must
be surfaced as a limitation.
