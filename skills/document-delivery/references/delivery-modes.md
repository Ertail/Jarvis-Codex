# Delivery modes

| Situation | Route | Review |
|---|---|---|
| Single source, simple summary | Direct | Source fidelity self-check |
| Multiple sources or major restructuring | Standard | Coverage and contradiction check |
| Executive, customer, legal, or public artifact | Reviewed | Independent review against sources |
| Existing artifact, formatting-only revision | Direct | Render/format check |
| Existing artifact, argument or narrative change | Standard | Re-run source coverage |

Human-reading artifacts may use polished HTML when visual hierarchy materially
improves comprehension. Agent-maintained plans and state should remain concise
Markdown or structured data.
