# Document Delivery

Produce a useful document without inventing source claims.

## Intake

Determine:

- source set and authority;
- deliverable type and format;
- audience and decision context;
- required inclusions and exclusions;
- factual, visual, and length constraints.

Ask only for missing information that would materially change the result.

## Analyze sources

Read each authoritative source before composing. Extract claims, evidence,
structure, terminology, contradictions, and intentional exclusions. For
multiple sources, distinguish agreement, conflict, and unique contribution.

Use the appropriate installed document, spreadsheet, presentation, PDF, image,
or browser skill when the source or output format requires it.

## Compose

Choose the lightest route:

- **Direct**: one clear source and a simple deliverable.
- **Standard**: multiple sources, substantial restructuring, or a defined
  audience.
- **Reviewed**: external/public deliverable, high consequence, or explicit
  request for independent critique.

Build the narrative around the audience's decision, not the source order. Mark
inference and preserve uncertainty. Never add unsupported facts for smoothness.

## Review and deliver

Check:

- source fidelity;
- requirement coverage;
- audience fit;
- internal consistency;
- factual attribution;
- visual/render quality when layout matters.

When using a reviewed route, apply `$independent-review` with the source set as
the external standard. Deliver the artifact, source summary, intentional
exclusions, verification performed, and any remaining limitation.

Read [references/delivery-modes.md](references/delivery-modes.md) for routing
examples.
